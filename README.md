# dbqn-sim
DBQN-Sim: An Open-Source Simulator for Decentralised Blind Quantum Computing Networks. Currently contains the script that reproduces the results of the DBQN paper; the full simulator is in development.

## Reproducing the paper's results

`calc.py` recomputes the values in Tables 2–5 and Figure 3 of the DBQN paper (Python 3, standard library only):

```bash
python3 calc.py
```
